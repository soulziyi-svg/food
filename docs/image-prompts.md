# ODD TABLE 이상한식탁 — 이미지 생성 프롬프트 목록 (52개 전체 파일 경로 적용)

> ⚠️ 이 문서는 **프롬프트 + 파일 경로 매핑 문서**입니다. 이 작업 환경(Claude Code)에는 이미지를 실제로 생성하는 도구가 없어 이미지를 임의로 생성하지 않았습니다.
> 각 카드마다 **예상 파일 경로**를 지정해 두었습니다. 외부 이미지 생성 도구(또는 실제 촬영본)로 만든 파일을 해당 경로 그대로 `image` 폴더 안에 넣기만 하면, 코드 수정 없이 바로 화면에 반영됩니다 (`js/data.js`가 해당 경로 존재 여부와 무관하게 참조하도록 다음 단계에서 연결).
> 파일이 아직 없는 카드는 지금처럼 `data.js`의 로컬 SVG 플레이스홀더(음식명 + 지역/카테고리 표시)가 그대로 유지됩니다.

## 폴더 구조

```
1차연습페이지0806/image/
├── 01.png, 02.png, 03.png        (기존 히어로 배너 2장 + 귀신 아이콘 — 적용 완료)
├── local/                         (향토음식 32개 — 8개 지역 × 4개)
│   ├── gangwon-ongsimi.png        (메인)
│   ├── gangwon-ongsimi-1.png ~ -3.png  (썸네일 3장)
│   └── ... (아래 표의 "예상 파일 경로" 참고)
└── horror/                        (호러음식 20개 — 5개 카테고리 × 4개)
    ├── horror-corn.png            (메인)
    ├── horror-corn-1.png ~ -4.png (모달 추가 이미지 4장)
    └── ... (아래 표의 "예상 파일 경로" 참고)
```

## 작업 절차 (매 이미지 공통 적용)

1. 섹션 제목/설명 분석
2. 핵심 키워드 3~5개 추출
3. 추출 키워드와 직접 관련된 이미지인지 적합성 판단 (5개 질문 모두 "예"일 때만 진행)
4. 관련 없는 음식/장소/소품/분위기용 이미지는 생성하지 않음
5. 최종 프롬프트에 **주제 · 정확한 이름 · 지역명 · 구도 · 분위기 · 조명 · 배경 · 색상 · 사용 위치**를 반드시 라벨로 명시
6. 관련성이 낮으면 placeholder 유지
7. alt 텍스트는 카드 제목 기준으로 정확히 작성
8. 파일이 준비되면 아래 표의 "예상 파일 경로"에 맞춰 저장

## 1. 향토음식 섹션 (`content1`) — 32개 카드

### Step 1 — 섹션 분석
- section title: "각 지역별 향토 음식" / subtitle: "Local Food Magazine"
- section description: "타 지역 사람들은 몰랐던 각 지방마다 알려지지 않은 향토음식이 많이 있습니다. 각 지역의 특색있는 알려지지 않은 음식을 소개합니다."

### Step 2 — 핵심 키워드 (3~5개)
지역명 + 정확한 음식명, 향토음식 유래, 재료/질감 클로즈업, 정갈한 전통 식기, 과하지 않은 배경

### Step 3 — 적합성 판단
32개 카드 모두 "카드 제목 = 지역명+정확한 음식명" 형태이고 `data.js`의 `region`/`name`/`summary`와 직접 일치 → 5개 질문 전부 "예" → **전부 생성 대상** (placeholder 사유 없음).

## 3. 서브 이미지(썸네일/추가 이미지) 규칙

- 향토음식 썸네일 3장(`-1.png`~`-3.png`): ① 조리 과정 클로즈업 ② 완성 음식 다른 각도 ③ 담음새를 보여주는 테이블 세팅 컷
- 호러음식 추가 이미지 4장(`-1.png`~`-4.png`): ① 소스가 흐르는 순간 매크로 컷 ② 완성 음식 다른 각도 ③ 어두운 테이블 세팅 컷 ④ 절단면/속재료 컷
- 모두 메인 프롬프트의 **[이름]·[지역]·[제외]**는 유지하고 [구도]만 위 항목으로 교체해서 생성합니다.

## 4. 코드 연결 방법 (파일 준비 후)

1. 이미지 생성 도구에 위 표의 "최종 이미지 프롬프트"를 그대로 입력해 결과물을 받는다.
2. Step 3의 적합성 판단 5개 질문에 다시 대입해 확인한다 (결과물이 라벨과 다르면 재생성).
3. 파일명을 표의 "예상 파일 경로" 그대로 저장해 `1차연습페이지0806/image/local/` 또는 `image/horror/` 폴더에 넣는다.
4. `js/data.js`에서 해당 항목의 `image`(및 `thumbs`/`extraImages`) 값을 플레이스홀더 대신 이 경로 문자열로 교체한다.
5. 파일이 아직 없는 카드는 그대로 두면 현재의 로컬 SVG 플레이스홀더(음식명 + 지역/카테고리 표시)가 유지된다.

- 관련성이 낮아 placeholder 처리가 필요한 항목: **없음** (52개 전 항목이 `data.js`의 실제 지역명/음식명/카테고리와 1:1로 일치)
